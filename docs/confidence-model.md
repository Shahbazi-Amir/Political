# Confidence Model

Confidence خروجی مدل نهایی نیست. Core بعد از مدل cap اعمال می‌کند. تک‌منبع ضعیف، source-chain مشترک، contradiction حل‌نشده، breaking/high-impact بدون corroboration، official statement تنها برای underlying fact، quote بدون original source، negative claim با archive coverage ناکافی، stale current evidence، search coverage پایین، retracted evidence و primary label بدون authority معتبر confidence را پایین می‌آورند. هدف اصلی کاهش `False High-Confidence Rate` است.
