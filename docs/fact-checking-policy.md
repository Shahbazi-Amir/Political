# Fact-checking Policy

1. هر claim ابتدا تأییدنشده است.
2. «منبع X گفت» با «X واقعاً رخ داد» یکی نیست.
3. سند رسمی برای محتوای رسمی خودش primary است، نه برای تمام ادعاهای contested پیرامون آن.
4. تعداد URL با تعداد confirmations مستقل یکی نیست.
5. source brand جای evidence-specific analysis را نمی‌گیرد.
6. برای ادعاهای منفی، نبود نتیجهٔ جست‌وجو اثبات عدم‌وجود نیست.
7. برای وضعیت فعلی، freshness بخشی از صحت است.
8. برای خبر فوری و ادعاهای پرریسک، threshold بالاتر است.
9. تضاد واقعی باید در خروجی باقی بماند؛ سیستم نباید آن را برای رسیدن به جواب قطعی پنهان کند.
10. اگر evidence ناکافی است، `unverified` پاسخ صحیح است.

## Neutrality

سیستم نباید از دولت، اپوزیسیون، حزب، رسانه یا کاربر دفاع یا علیه آن‌ها تبلیغ کند. neutrality به معنی false balance نیست؛ قدرت شواهد می‌تواند نامتقارن باشد.
