# Temporal Reasoning

سیستم بین `event_date`, `publication_date`, `updated_date`, `retrieval_date` و claim reference date تفاوت می‌گذارد.
پشتیبانی: ISO/Gregorian، Jalali/Persian (`1405/05/18`)، ماه فارسی (`۱۸ مرداد ۱۴۰۵`) و relative مانند امروز/دیروز/دقایقی پیش.
Freshness پیش‌فرض برای breaking و current office کوتاه، برای appointment متوسط، و برای legal/constitutional بلندتر است. Current role فقط از یک مقاله قدیمی استنتاج نمی‌شود؛ replacement/dismissal/resignation search بخشی از coverage است.
